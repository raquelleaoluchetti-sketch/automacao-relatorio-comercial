# automacao-relatorio-comercial
CRM Sales Data Automation: Script em Python para automatizar a extração, limpeza e análise de dados de vendas de CRM. Gera relatórios estruturados e prontos para tomada de decisão. Limpa dados, calcula KPIs e exporta para Excel multi-abas, otimizando o tempo de preparação de relatórios operacionais. Tecnologias: Python, Pandas, OpenPyXL.
